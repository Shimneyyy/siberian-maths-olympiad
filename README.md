# Личный кабинет Сибирской математической олимпиады

Техническая основа: Next.js 16, React 19, TypeScript, Tailwind CSS 4,
компоненты в стиле shadcn/ui, PostgreSQL 17 и Prisma 7. Три роли:
студент, главный организатор и организатор площадки.

## Текущее состояние

Стартовая страница работает, регистрация и вход ещё не реализованы. ПДн не собираются.
Созданы базовая модель и SQL-миграция. Полная проверка Prisma в текущей облачной
среде заблокирована доступом к binaries.prisma.sh. Это не готовый к запуску ЛК.
Состояние проверок и продолжение — [HANDOFF](docs/HANDOFF.md).

## Локальная разработка

Нужны Node.js 24, npm и Docker Compose. `.env` не коммитится.
Команды выполняются в корне checkout.

```sh
cp .env.example .env
npm ci
docker compose up -d --wait
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

Не перезаписывайте существующий `.env`. Реквизиты в примере предназначены только
для локальной БД. Скрипт seed добавляет демонстрационные справочники без пользователей
и юридических согласий; повторный запуск не создаёт дубликаты.
SMTP-песочница: порт 1025, интерфейс Mailpit: порт 8025. Отправка из приложения пока
не реализована. PostgreSQL: порт 5432; все порты сервисов привязаны к loopback.

Необходимый исходящий доступ при установке: registry.npmjs.org и binaries.prisma.sh.
TLS и проверку контрольных сумм Prisma не отключать. В облачной среде доступ к
последнему домену добавлен в черновик настроек, но ещё не применён.

## Проверки

После генерации клиента и применения миграции:

```sh
npm run lint
npm run typecheck
npm run test:db
npm run build
npm start
```

`test:db` запускайте только с отдельной локальной/тестовой БД: он создаёт синтетические
записи, проверяет ограничения и очищает их. Production-БД для него недопустима.
`GET /api/health` возвращает 200 при доступной БД, 503 при недоступной, без подробностей
ошибки. Этот endpoint не заменяет функциональную приёмку.
Для изменения схемы: `npm run db:dev -- --name <name>`; созданную миграцию коммитить.
Для остановки сервисов без удаления данных: `docker compose stop`.
