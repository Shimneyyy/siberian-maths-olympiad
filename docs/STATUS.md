## Изменения по запросу пользователя

- Текущий капитан до закрытия может удалить свою команду с подтверждением, не
  отменяя ничьего участия. Приглашение можно получить, уже состоя в другой команде;
  принять — после выхода/удаления прежней. Входящие приглашения сохраняются.
- Старый логин nsuhw сохраняется обычным вводом без проверки принадлежности
  организатором. Review/approve интерфейс и API удалены. Новая миграция сохраняет
  ранее введённые логины и убирает только поля модерации.
- Согласованный CSV результатов: ФИО,Курс,Вуз,Логин,Задача 1,…,Сумма баллов;
  Приз необязателен, прежний формат работает. Сопоставление по точному логину и году,
  неоднозначные логины отклоняются. Дополнительные поля не меняют профиль.
- Импорт отдельно от публикации; после публикации результат доступен своему
  участнику и в его истории. Старый логин больше не ожидает подтверждения.

## Продолжение технической очереди

Сервисы назначений требуют пароль независимо от HTTP; ошибки lookup сессии и
denial-аудита возвращают фиксированный 503/no-store. Auth использует атомарные
лимиты по адресу/token вместо общего bucket. Клиентские запросы ограничены по времени,
ручной отказ экспорта/явки очищает список и polling; Back проверяет владельца сессии.
Объём проверок и остаток — [отчёт](archive/investigations/QUEUE_HARDENING.md).
Продолжение 21 ноября: формы CSV очищают исходник и предпросмотр при потере доступа,
при конфликте требуют новой проверки, при потере ответа сохраняют идентификатор для
повтора без дублей. [Проверки текущего пакета](archive/investigations/IMPORT_FORM_RECOVERY.md).

## Границы

Только синтетические данные и @example.test; production, реальные ПДн, публикация
среды и merge в main не разрешены. Три предметные роли и отдельный единственный
технический администратор. Прямой API/SSO nsuhw, общая внешняя таблица, командный
импорт результатов, исправление/отзыв опубликованных результатов не реализованы.
Справочники вуза/курса доступны главному, подготовка PDF ограничена advisory locks
между процессами. Есть ручное восстановимое перемещение orphan без удаления;
автоматической уборки, OS sandbox и production-проверки свежести AV пока нет. Подтверждение создания новых сгенерированных аккаунтов
сохранено и не является отменённой проверкой принадлежности старого логина.
