# ADR-009: старый логин без модерации и таблица результатов

Статус: принято по запросу и уточнению пользователя 20 ноября 2026.
Заменяет часть ADR-003/E00 о проверке принадлежности старого аккаунта.

Участник просто вводит старый логин nsuhw; организатор не проверяет владельца.
Поле становится доступным для сопоставления результатов/дипломов сразу. Review/
approve API, интерфейс модерации и поля approved* удаляются миграцией. Все ранее
сохранённые логины, включая ожидавшие проверки, сохраняются и используются сразу.

Непустой формат/длина, собственная сессия и права продолжают проверяться;
старый пароль не собирается, внешних запросов проверки нет. Дубли самовведённого
логина не блокируют сохранение, но неоднозначный импорт не назначает результат
наугад. Нет автоматической перепривязки или замены уже выданного нового аккаунта.
Это не отменяет подтверждение реального создания новых сгенерированных аккаунтов.

Согласованный состав таблицы: ФИО, курс, вуз, логин, баллы по задачам, сумма баллов.
CSV-шаблон и прежний формат поддерживаются совместно. Логин — ключ сопоставления
с участием выбранного года, дополнительные поля — для предпросмотра, не для
перезаписи профиля. Сумма готовая; публикация отдельно от импорта. После неё
личное достижение доступно только соответствующему студенту и в его истории.
