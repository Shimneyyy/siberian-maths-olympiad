# ADR-003: отдельные внешние аккаунты и ручная передача

Статус: частично заменено [ADR-009](ADR-009-self-reported-login-and-results.md)
от 20 ноября 2026. Ниже сохранена причина прежнего решения; проверка принадлежности
старого логина больше не действует. Остальные правила генерации/выдачи сохранены. Источник: Q02/E00–E06 от 8 ноября 2026 и
E02/E03 от 9 ноября в [исходном журнале](https://github.com/Shimneyyy/siberian-maths-olympiad/blob/a921c0981bc041336760c309e1dd527c61202140/docs/DECISIONS.md#L643).

## Причина и решение

Пароль ЛК хранится хешем и не экспортируется. Пользователь подтвердил раздельный
пароль nsuhw, сохранение старых аккаунтов и внешнего аккаунта между годами.
Связь сайтов — переход, без SSO/API/автоматического создания.

Первоначально старый логин проверял главный; это правило отменено ADR-009.
Теперь старый логин сохраняет пользователь без модерации.
Совпадение ФИО/заявленного логина не доказывает владение. Старый пароль не собирается.
Новая генерация запрещена при любой собственной legacy-заявке. Отдельные латинские
имя/фамилия не заменяют официальное ФИО; новый логин неизменен после подготовки.

Prepared-кандидат не означает внешний действующий аккаунт. Главный вручную
скачивает CSV, передаёт в nsuhw и отдельно подтверждает успех; только затем владелец
получает защищённый повторный показ. Для исторического готового источника есть
отдельный CSV-импорт по UUID, без замены prepared/legacy. Частичность только по
ошибкам строк, а не по инфраструктурному сбою.

## Последствия

Для повторного показа/экспорта нужен обратимо зашифрованный внешний секрет, не
пароль ЛК: envelope AES-256-GCM с отдельными ключами и AAD. Год не входит в AAD
глобального аккаунта. Namespace общий с legacy, локальная уникальность не доказывает
отсутствие неизвестных аккаунтов на внешнем сайте.

Письма без паролей; экспорт — контролируемое исключение с plaintext attachment,
защищённой ручной передачей и удалением скачанного файла оператором. Скачивание
не является подтверждением, тестовая отметка не является реальной интеграцией.
Импорт использует HMAC с auth-секретом отдельно от шифрования внешнего пароля.

[Контракт, код и лимиты](../contracts/NSUHW.md). Перепривязка/исправление ошибочного
выбора, реальный формат nsuhw и production-KMS остаются открытыми; не изобретать
замену или восстановление неизвестного старого пароля.
