# ADR-017. Кабинеты, импорт и локальная доставка

Принято 25 ноября 2026 по запросу пользователя для ветки work1.

- Выпуск по-прежнему уникален по году. Кабинеты показывают годы в обратном
  хронологическом порядке. Выбор «текущего» и новое ручное закрытие убраны.
  Старое ручное закрытие снимается при сохранении сроков техническим администратором.
- На выпуск допускается одно действующее назначение главного организатора.
  Замена отзывает прежнее назначение и сессии, сохраняя историю.
- Главный может удалить неиспользуемую запись справочника. Ссылки профилей,
  заявок и команд защищены внешними ключами.
- Командный CSV поддерживает сопоставление по названию команды и полному набору
  логинов. Прежний CSV с ID поддерживается для уже подготовленных файлов.
- Новый пароль ЛК и новый генерируемый пароль nsuhw имеют восемь символов.
  Ранее установленные пароли работают до смены или сброса.
- Проверка PDF остаётся изолированной и входит в обычный локальный Compose.
  Команда npm run dev запускает обработчик outbox в учебном режиме.

Изменения уточняют [ADR-002](ADR-002-annual-participation-and-teams.md),
[ADR-012](ADR-012-team-results-and-courses.md) и
[ADR-016](ADR-016-cabinet-cleanup.md).
