# ADR-012: командные результаты и курсы участников

Принято 21 ноября 2026. Источник — предложение отдельного CSV по ID команды с
баллами/суммой/призом и снимком состава; пользователь уточнил «Еще курсы участников».
Заменяет отложенный статус командного импорта в [ADR-004](ADR-004-publication-and-versioning.md).

Год выбирает главный своего назначения. Команда сопоставляется по UUID, имена и
курсы из CSV не являются ключом. Состав, ФИО, курс и вуз берутся из заявок и
фиксируются при импорте. Достижение принадлежит этому составу, даже после выхода,
перехода, исправления профиля или удаления команды. Поздние участники автоматически
не получают старое достижение. В preview показаны и метаданные CSV, и реальные курсы.

Импорт частичный, все дубли команды отклоняются. Предварительные/итоговые отдельны;
задачи общие с личными результатами года. Повторный CSV не заменяет существующий
результат: исправление через версии ADR-011. Публикация отдельная.
Студент читает достижения своего фиксированного состава; организатор площадки
получает данные только в своей области, состав вне области не раскрывается.
