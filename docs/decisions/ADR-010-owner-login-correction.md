# ADR-010: исправление старого логина владельцем

Принято 21 ноября 2026. Источник — ответ пользователя «Разрешить участнику» на
предложение менять только собственный старый логин, сохраняя достижения и prepared.
Уточняет [ADR-009](ADR-009-self-reported-login-and-results.md).

Подтверждённый студент исправляет свою декларацию без проверки принадлежности
организатором. Требуется актуальная revision; User блокируется перед namespace.
Уже привязанные результаты и дипломы остаются у прежнего Participation.
Подготовленный новый аккаунт/его пароль не заменяются. Ни старый пароль, ни
новая генерация для исправления не нужны. Дубли заявленного логина не дают
доступа к чужим данным: будущий неоднозначный импорт отклоняется.

Аудит сохраняет ID/revision, без старого/нового логина.
