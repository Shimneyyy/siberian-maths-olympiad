# ADR-015. Удаление антивируса из загрузки дипломов

Решение пользователя от 21 ноября 2026 отменяет часть ADR-013 о проверке ClamAV
и свежести сигнатур. Профиль Docker для файлов запускает PDF-worker и relay.

Проверка дипломов включает лимиты загрузки и ZIP, разбор структуры PDF
и отклонение активного содержимого в изолированном контейнере.
SHA-256 связывает проверенные байты с сохранённым файлом.
При недоступности парсера загрузка завершается ошибкой.

Миграция данных для этого изменения не требуется.
[Контракт дипломов](../contracts/DIPLOMAS.md)

На базе f4c90c4 при остановленных контейнерах ClamAV прошли 17 файловых тестов,
браузерный сценарий с дипломами и три теста эксплуатации, включая восстановление
копии. Проверка готовности, lint, TypeScript, сборка и проверка её трасс прошли.
