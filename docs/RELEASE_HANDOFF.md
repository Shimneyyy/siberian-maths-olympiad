## Production остаётся запрещён

Нужны оператор ПДн, настоящие документы/основания бессрочного хранения и процедура
для несовершеннолетних. Не выбраны/не приняты российские production-провайдеры
БД/файлов/копий/почты и KMS, ответственные, HTTPS/proxy/CDN, мониторинг/инциденты,
scheduler копий/истечения и независимый журнал обращений. Нужны их реальная приёмка
по RPO 24ч/RTO 8ч, инфраструктурная нагрузка с запасом, проверка настоящего импорта
nsuhw и процедура при утрате всех MFA-факторов. Это отдельный этап с оператором;
юридические заглушки/локальный CI не закрывают эти условия. Реальные ПДн запрещены.
