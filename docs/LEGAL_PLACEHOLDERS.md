# Временные юридические заглушки

Это перечень незаполненных юридических требований, не политика обработки ПДн
и не текст согласия. Оператора не выдумываем. Пользователь разрешил учебные заглушки.

До сбора реальных данных необходимо:

- Указать юридическое лицо оператора, адрес и контакт для обращений субъектов ПДн.
- Утвердить цели, основания и минимальный состав данных для каждого процесса.
- Утвердить правила участия несовершеннолетних, основания обработки их данных,
  случаи и проверяемый порядок участия законного представителя. Не добавлять
  сбор паспортов/свидетельств/данных родителей без установленной необходимости.
- Подготовить реальные тексты политики, согласий, уведомлений и их версионирование.
- Определить сроки хранения, отзыв/удаление/обезличивание, обработчиков и размещение.
- Проверить законность публикации результатов и передачи данных оператору nsuhw.

В коде пока используется `demo-only-v1` с назначением `synthetic-demo-only`.
Отметка означает только обещание использовать вымышленные данные. Она не разрешает
обработку настоящих ПДн. Dev-регистрация требует DEMO_REGISTRATION=true и @example.test;
в production она закрыта независимо от флага. Для открытия реальной регистрации
нужны готовые документы, приёмка оператором и отдельное изменение кода с тестами.
