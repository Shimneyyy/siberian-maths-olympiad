# План небольших задач

> Обновление согласования: см. [DECISIONS.md](DECISIONS.md). Принятые там решения
> уточняют первоначальный проект ниже. Техническая основа разрешена; отдельного администратора нет.
> Аккаунты nsuhw сохраняются между годами, новым участникам данные генерируются.

Статус: этап 1 реализован и проверен в учебном контуре; сетевой блокер снят. Qxx определены в ARCHITECTURE.md. Каждая строка
— отдельная задача/PR; при превышении объёма одного review её нужно разделить.
Зависимость означает завершение приёмки, а не только начало работ.

## Текущий прогресс

Техническая основа и аутентификация этапа 1 (B01–B08) реализованы и проверены
в учебном контуре. Это не готовность к production и не реализация ежегодного участия.

| Задача | Результат |
| --- | --- |
| B01 | Каркас/UI/lockfile, lint, типы и production-сборка проходят |
| B02 | PostgreSQL и Mailpit работают, код и ссылка сброса действительно доставляются |
| B03 | Обе миграции применены, diff модели и БД пуст, повторный seed без дублей |
| B04 | Серверная политика с годом/площадкой, аудит; негативные тесты ролей и отзыва |
| B05 | Учебная регистрация с атомарным профилем и учебной отметкой, email OTP; production закрыт |
| B06 | Вход/выход, сессии, восстановление, одноразовые коды/ссылки, CSRF и ограничения частоты |
| B07 | TOTP, первоначальное назначение главного через CLI, назначение/отзыв организаторов площадки через кабинет с повторной проверкой пароля |
| B08 | CI дополнен семью проверками БД/политики/назначений и двумя HTTP-сценариями с локальной почтой; локальные команды проходят, удалённый результат CI требует отдельной проверки |

Юридическая приёмка и реальная регистрация B05 отложены до определения оператора
и процедуры для несовершеннолетних. Production-усиление B06/B07 (proxy, HTTPS,
эксплуатационный секрет, аудит хранения) остаётся воротами F03–F04.
Первый следующий предметный этап: C01–C04 (выпуски, сроки, площадки, ежегодное участие).
C05–C08 затем добавят списки, экспорт и явку. Таблицы назначений/площадок в текущей
схеме не означают, что пользовательское управление площадками C02 уже реализовано.
Дальнейшие решения по nsuhw и формату результатов — DECISIONS.md.
