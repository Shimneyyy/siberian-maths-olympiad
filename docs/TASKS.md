# Открытые задачи

База: аудит a921c09; актуализация по изменениям после 66e7778 от 20 ноября 2026. Это активная очередь; завершённые отчёты —
[архив расследований](archive/investigations/BUGFIX_HISTORY.md). Наличие гипотезы
не означает доказанный дефект. Реорганизация документации и текущие изменения поведения — разные этапы.

## Техническая очередь

| ID | Статус | Следующий конкретный шаг и критерий |
| --- | --- | --- |
| UI01 | Частично закрыта | Меню четырёх ролей исправлено; проверить остальные формы/таблицы desktop/375px, overflow и клавиатуру. Не считать проверку меню полной визуальной приёмкой |
| SEC02 | Частично закрыта | Неверный UTF-8 теперь 400. Проверить отказ БД/session lookup и denial-аудита вне части catch: фиксированные ответы/no-store без исключений |
| SEC03 | Открыта, подтверждено кодом | Пароль/лимит staff сейчас только в api/staff/route.ts. Перенести защиту в прикладной сервис с регрессией прямых assign/revoke и HTTP, без расширения прав |
| SEC04 | Требует проверки/инфраструктуры | Проверить конкурентные auth rate limits, OTP/reset enumeration и общий bucket. Доверенный proxy/IP согласовать до production |
| SEC05 | Известные ограничения | Per-process preparing Set, синхронный ZIP, orphan/crash, общий UID PDF-процесса. Нужны квоты нескольких процессов, безопасная cleanup-процедура, OS sandbox и AV freshness |
| UX02 | Требует проверки; часть видна в коде | Матрица manual/polling 401/403/offline/slow/stale/Back для форм и таблиц. У ручной attendance/export-ошибки appliedQuery не обнуляется; проверить остановку polling и очистку данных |
| OPS01 | Заблокирована условиями запуска | Закрывать только с реальной инфраструктурой/оператором и отдельным разрешением; [условия](OPERATIONS.md) |
| WSL-VERIFY | Ожидает проверки пользователя | Реальный перенос Windows → WSL, сохранение прежней БД/.env/ключей, успешная регистрация/вход на его машине; Linux-тесты этого не доказывают |

SEC01 (чужие сессии при отзыве), AUTH05 (локальный verify-режим), AUTH06 (ложный успех
resend), pg adapter, сообщения регистрации/Latin autofill и пустой admin UI исправлены
в коде до базы аудита. Это не новое подтверждение runtime в текущей задаче.

## Расхождения и несогласованные возможности

| ID | Состояние и требуемое решение |
| --- | --- |
| DOC-CATALOG / Q11 | Принято «справочники ведёт главный», но есть лишь seed вуза/курса. Согласовать UI/API либо ограничение первой версии; не считать управление реализованным |
| NSUHW-RELINK / Q02 | Изменение ошибочно введённого старого логина, замена prepared и смена внешнего пароля пока не реализованы. Проверка принадлежности старого логина отменена новым решением. Не обходить прямым SQL или новой генерацией |
| RESULTS-CORRECTION / Q08 | Исправление/отзыв импортированных результатов и публикаций не реализованы; immutable-защиту сохранять до нового решения |
| TEAM-RESULTS / Q08 | Командный импорт результатов отложен решением пользователя, не отмечать выполненным |
| FILE-ORPHANS / Q09 | Сроки/процедура уборки файлов без DB-связей не согласованы. Не удалять опубликованные/исторические бессрочные версии под видом cleanup |
| PRODUCTION / Q12–Q13 | Оператор/основания хранения/провайдеры/KMS/канал nsuhw/мониторинг/scheduler/допуск остаются открыты; локальные тесты их не закрывают |

Три предметные роли плюс отдельный технический администратор — действующее R03,
не открытый вопрос и не предложение изменить код. Раздельные пароли, перенос главным,
частичный импорт и отдельная публикация также уже приняты: [реестр](DECISIONS.md).

## Правило обновления

У задачи один статус, ссылка на контракт/решение и критерий завершения. После исправления
записать ревизию, выполненные проверки и остаток работ один раз; не копировать отчёт
в архитектуру, AGENTS и решения. Закрытые задачи не возвращать в очередь по старому
архивному описанию. Новые бизнес-процедуры требуют решения пользователя.
