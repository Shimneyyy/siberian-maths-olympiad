# Справочники вузов и курсов

Реализация ранее принятого Q11, 20 ноября 2026. Источник решения —
[ADR-002](../decisions/ADR-002-annual-participation-and-teams.md).
[Сервис](../../src/lib/catalogs.ts), /cabinet/catalogs, GET/POST /api/catalogs.

Главный с действующим назначением на выбранный год читает и меняет общие
справочники всех годов. Остальные роли доступа не получают. Запись требует
текущий пароль, общий correction-reauth limit, повторную авторизацию в транзакции,
advisory lock и аудит без названий. UUID/revision обязательны для обновления;
устаревшая revision и совпадающее без учёта регистра название дают конфликт.
Новая запись имеет revision=0; изменение увеличивает её.

Название 1–200 символов, вуз также требует аббревиатуру 1–30 символов.
Можно создать, переименовать, отключить или включить; физического удаления в API нет.
Отключённое значение не предлагается для новых выборов в регистрации/профиле;
исторические Participation хранят прежние название/аббревиатуру/курс независимо
от текущей записи справочника. Изменение каталога не переписывает снимки.

SQL-миграция 20261120100000_catalog_revisions добавляет обеим таблицам revision=0
и неотрицательный CHECK, сохраняя существующие записи.
