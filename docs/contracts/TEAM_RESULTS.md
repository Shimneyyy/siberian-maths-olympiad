# Командные результаты

[ADR-012](../decisions/ADR-012-team-results-and-courses.md),
[team-results.ts](../../src/lib/team-results.ts), /cabinet/team-results-import.
Доступ к preview/apply/списку ID — главный своего назначенного года.

```csv
ID команды,Курсы участников,Задача 1,Задача 2,Сумма баллов,Приз
00000000-0000-4000-8000-000000000001,"1; 2",4,,12,Учебный приз
```

UUID в примере условный: настоящий берётся из «Показать команды для CSV».
POST /api/results/teams/roster — год/page, по 25 команд с составом/курсами/вузами.
CSV UTF-8 до 2 МиБ, 10000 строк, 1–50 задач, те же правила кавычек/чисел/null,
что у [личных результатов](RESULTS.md). Обязательны ID команды, задачи по порядку
и Сумма баллов (или Сумма); Название команды, Курсы участников, Вуз и финальный Приз
необязательны. Реальные курсы всегда извлекаются из заявок, даже без столбца в файле.
Метаданные CSV служат сверке, не переписывают заявки и не заменяют UUID.

POST /api/results/teams/preview возвращает строки/ошибки, актуальный состав и
selectionHash. POST /apply дополнительно требует стабильный id, hash, пароль,
confirmed. JSON для этих двух маршрутов до 4 МиБ. Все дубли UUID (включая другой
регистр), неизвестная/чужого года команда, существующий результат этого вида
отклоняются построчно. Число задач должно совпадать с задачами года.

Apply блокирует выпуск, повторно проверяет hash/состав/назначение; изменение снимков
между preview и apply даёт 409. TeamResultImport хранит hash/счётчики/коды, без CSV.
ResultDocument связывает исходный UUID/название команды и неизменяемый снимок
получателей с ФИО/курсом/вузом. Профиль, новый состав и удаление команды не меняют
снимок и не передают старое достижение новым людям. Несколько команд в разные годы
остаются отдельными достижениями. Повтор UUID не создаёт дубли.

Импорт не публикует и не отправляет уведомлений. Публикация, исправление и отзыв —
[общий контракт версий](RESULTS.md#исправление-и-отзыв). До публикации участник ничего
не видит; после — в результатах и истории отображаются команда, оценки и курсы
фиксированного состава. SQL сохраняет версии/получателей/события бессрочно.
