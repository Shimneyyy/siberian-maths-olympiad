# Приватные дипломы

Обновлено 20 ноября 2026 после 66e7778. [ADR-004](../decisions/ADR-004-publication-and-versioning.md).
Сервис [diplomas.ts](../../src/lib/diplomas.ts), страница /cabinet/diplomas.
Главный назначенного года загружает, назначает и отдельно публикует; студент видит
свои текущие опубликованные документы. Организатор площадки и технический администратор
не наследуют доступ. Несколько документов одному человеку — отдельными пакетами.

## Входной ZIP

PDF в корне, имя <точный логин nsuhw>.pdf. Год выбирает главный;
совпадение ФИО не используется. Логин должен однозначно соответствовать участию года
подтверждённого по email студента @example.test с confirmed prepared либо
самовведённым старым логином без проверки организатором. Дубли логина у участников
этого года дают ошибку соответствия; принадлежность по ФИО не угадывается.
Отменённое участие само по себе не исключает соответствие.

Лимиты: ZIP 50 МиБ, до 1000 записей, PDF 10 МиБ. multipart ограничивается до разбора
50 МиБ + 16 КиБ; годовые права проверяются перед чтением большого тела. Допускаются
только id/file/password/confirmed без дублей; editionId — отдельный UUID query.

[zip-preview.ts](../../src/lib/private-files/zip-preview.ts) последовательно читает
stored/deflate без извлечения путей на диск; ограничивает размеры, CRC, ratio=200,
expandedBytes=1000×10 МиБ и время 60 секунд. Заголовок %PDF- — только preflight,
не доказательство безопасности. Все дубли точного логина отклоняются, написание
логина сохраняется; регистр расширения не меняет идентичность.

Повреждение/нарушение общих лимитов или невозможность чтения ZIP прерывают пакет.
Неподдерживаемые записи (в том числе шифрованные/ссылки/специальные объекты),
неподходящие имена, неподходящий PDF и недоступное соответствие отмечаются ошибками
строк, когда архив удалось безопасно разобрать. Это не безусловное обещание полного
отказа только из-за наличия одной шифрованной записи: смотреть реализацию parser.

## Реальная проверка PDF

[Клиент проверки PDF](../../src/lib/private-files/pdf-inspection.ts) отправляет копию
байтов в [изолированный парсер](../../scripts/check-passive-pdf.mjs) и вычисляет
SHA-256 этой копии. Парсер отклоняет зашифрованные PDF, активные объекты, JavaScript,
действия, формы, вложения и внешние URI. Проверка основана на структуре PDF.
Антивирусное сканирование исключено по [ADR-015](../decisions/ADR-015-remove-antivirus.md).

PDF: 1–100 страниц, глубина 100, 100000 посещений объектов. Проверка выполняется
через http://127.0.0.1:3320/inspect в отдельном контейнере: UID 10001, root read-only,
cap_drop=ALL/no-new-privileges, 512 МиБ/1 CPU/64 PID. Ни исходников сайта, ни host mounts,
ни ключей, ни хранилища дипломов внутри нет. Только внутренняя Docker-сеть, без
внешнего выхода. Фиксированный TCP relay публикует loopback-порт, не разбирает PDF
и не принимает выбираемый адрес. Приложению Docker socket не передаётся.

В контейнере Node --jitless, prlimit core=0/data=256 МиБ/CPU=10с, old-space=96 МиБ,
wall=12с, stdout до 512 символов, stderr не передаётся наружу. Вход — байты в памяти,
без временных PDF. Клиентский timeout 15с; недоступность/перегрузка/неверный ответ
означают 503, fallback на неизолированный процесс отсутствует.
После npm ci запустите профиль files командой из README.
Образы/ограничения — [compose](../../compose.yaml), [ADR-013](../decisions/ADR-013-isolated-file-inspection.md).

## Подготовка, назначение и публикация

POST /api/diplomas/upload: подтверждение/пароль/общий reauth главного. Один actor
может готовить один пакет; одновременно в одной БД — не более двух подготовок.
[Транзакционные advisory locks](../../src/lib/private-files/preparation-lease.ts)
координируют независимые процессы и освобождаются при обрыве соединения. В HTTP
lease захватывается до чтения multipart. Размер проверяется по фактическим байтам,
чтение ограничено 30 секундами (408 при превышении); квота удерживается до конца
подготовки. Общий proxy limit остаётся дополнительной защитой до процесса приложения.
Подготовка последовательна в HTTP-запросе, не фоновая очередь. Перед каждым следующим
файлом проверяется бюджет 300с; уже начатый ограничен своими тайм-аутами.
Нагрузка 1000 максимальных PDF не принята; крупный ZIP может потребовать разделения.

Проверенные файлы пишутся случайными ключами в .local/diplomas либо DIPLOMA_DIRECTORY
через [DemoQuarantine](../../src/lib/private-files/quarantine.ts): приватные права,
no-follow, hash, запрет public/.next/out. Успех put сам не означает AV-проверку.
Все items/отчёт и аудит фиксируются в БД атомарно. UUID/hash ZIP связывают повтор;
новый выбор файла — новая попытка. ZIP на сервере не сохраняется.
Сбой инфраструктуры прерывает попытку и удаляет созданные файлы по возможности;
crash/ошибка удаления могут оставить orphan. Автоматической уборки нет; безопасное
ручное перемещение без удаления описано в [жизненном цикле](../DATA_LIFECYCLE.md).
По уточнению пользователя при неуспехе нет автоматической публикации, обращения
или уведомления об успешной загрузке. Ошибка остаётся в интерфейсе организатора;
студент при необходимости обращается самостоятельно.

POST /api/diplomas/review показывает пакет/ошибки/соответствия. Apply требует все
корректные файлы: каждому новый документ или явная замена того же участника/года с
revision. Apply создаёт версии, не меняет currentVersion. Publish — отдельное
подтверждение/пароль; проверяет файлы и под блокировкой года переключает указатели,
увеличивает revision, пишет аудит/outbox атомарно.

До публикации замены старый PDF доступен, после — только новый, включая главного.
Повтор старой публикации не оживляет прежнюю версию. Конкурирующая опубликованная
замена делает stale-пакет конфликтным целиком; нужен новый пакет. FK/CHECK/триггеры
защищают год/владельца/метаданные/версию и неизменяемое содержимое.

## Скачивание и хранение

GET /api/diplomas/mine — свои документы; POST /api/diplomas/download принимает
только documentId, не fileKey/hash/userId/version. Студент — собственник, главный —
назначенный год. Читается текущий опубликованный PDF с hash; права/указатель версии
повторно проверяются в транзакции, аудит обязателен до выдачи.
Attachment, application/pdf, private/no-store/no-cache/no-referrer/nosniff/sandbox;
имя — UUID документа без ФИО/логина. Скачанный локальный файл нельзя отозвать.

Уведомление без PDF/логинов/токенов, повтор публикации не создаёт письмо.
Все версии хранятся бессрочно по [учебной политике](../DATA_LIFECYCLE.md);
не смешивать orphan с историческими версиями. Runtime-файлы исключены из Git/traces.

Перед production требуется принять изоляцию на целевом сервере, приватное хранилище,
резервное копирование, сроки хранения и правовые условия.
Проверки ZIP и PDF описаны в [TESTING](../TESTING.md).
