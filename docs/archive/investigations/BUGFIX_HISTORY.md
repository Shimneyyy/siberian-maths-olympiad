[BUGFIX_PLAN](https://github.com/Shimneyyy/siberian-maths-olympiad/blob/a921c0981bc041336760c309e1dd527c61202140/docs/BUGFIX_PLAN.md),

При реорганизации runtime-наборы не повторялись. Открытые задачи вынесены в [TASKS](../../TASKS.md).

## Auth и первый пакет

Auth investigation подтвердило DOM-autofill email без React onChange: форма брала
старое состояние. Email перенесён в FormData. Без пользовательской БД это не
объявлялось доказанной причиной конкретного сообщения пользователя.

Первый аудит исходил из 13e7ad6. SEC01 воспроизводился как неправомерное завершение
чужих сессий при отзыве без назначения адресата; чтение чужих ПДн этим не доказано.
Исправление требует подходящее назначение, повтор отзыва не завершает новые сессии.
AUTH05 исправил локальный verify-режим после OTP на /login, AUTH06 — ложный успех
resend и чтение email при autofill. UI01 закрыл меню, но не всю визуальную приёмку.
SEC02 исправил неверный UTF-8, сохранив открытыми инфраструктурные вопросы.

## AUDIT02: PostgreSQL

Код 215f7b1: предупреждение воспроизводилось в relation loader Prisma, несмотря
на последовательный прикладной await. Общая фабрика очереди на транзакцию исправила
его без патча зависимостей/фильтра предупреждений. [Решение](../../decisions/ADR-007-postgres-transaction-adapter.md).
Исторический отчёт: test:pg 12/12, DB 121/121, HTTP 6/6, live/load по 1/1,
lint/typecheck/build/check:build; load p95 3179 мс/max 3573 мс. Это локальный прогон,
не новый удалённый CI или production SLA. Ошибочная начальная void-фикстура была
исправлена до достоверной проверки; её сбой не приписывался приложению.

## AUDIT03: регистрация и Windows

Код df9c527: native Windows не обеспечивает POSIX mode-проверку keyring;
добавлен явный отказ до изменения файла и инструкция WSL, без ослабления 0600.
Конкретные метаданные пользовательского файла и успешность переноса не доказаны.
Разделены rollback keyring и SMTP failure после commit, сообщения фиксированные.
Латинские поля signup стали читаться из FormData после отдельного воспроизведения.

Исторические локальные итоги: DB 122/122, registration 2/2, HTTP 6/6,
account-switch 3/3, lint/typecheck/build/check:build, 75 traces. Windows guard проверен
подменой platform в изолированном процессе, без настоящего Windows executor.
Остальные наборы не выдавались за повторённые; новая удалённая приёмка не подтверждена.

## AUDIT04: пустой кабинет

Код a921c09: на БД без выпусков admin UI раньше показывал только вводный абзац.
Добавлены empty state, объяснение provisioning оператором и обновление; CLI-права
и назначение главного по выпуску сохранены, API создания выпуска не добавлен.

Исторические локальные итоги: account-switch 4/4, включая настоящий edition:create
и UI/grant БД, lint/typecheck/build/check:build, 75 traces и Markdown/diff-проверки.
DB/HTTP/load/files/ops в этом UI-пакете не повторялись; новый удалённый CI не подтверждён.
[Действующий ручной сценарий](../../MANUAL_TESTING.md), [WSL](../../WINDOWS_WSL.md).
