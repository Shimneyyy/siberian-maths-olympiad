## Объём

Новые согласованные процессы описаны один раз в ADR-010…013 и контрактах. Добавлены
сервисы/SQL/HTTP/UI/тесты версий, командного импорта и исправления логина, ранняя квота
загрузки, изолированный PDF-service, freshness/updater, proxy/IP limit и preflight.
Общий X-SMO-Actor предотвращает запись старой формы после смены аккаунта в другой
вкладке. Идемпотентность сохраняется при потерянном ответе после реального commit.

Сохранились три предупреждения Turbopack о dynamic filesystem tracing.
Проверка traces проверяет пути, не является универсальным сканером секретов.
Нагрузочный сценарий — 200 подготовленных сессий и 600 запросов, не 200 password-login
и не максимальный одновременный импорт PDF. Визуальное утверждение заказчиком и
целевая инфраструктурная приёмка не подменяются автоматическим smoke.


Миграция проверяется на заполненной прежней схеме: исходные результаты не меняются,
публикация/ноль/приз сохраняются в версии 1. Проверяются роли/год/владелец/stale,
конкурентные исправления, audit/outbox rollback, сохранение командных курсов после
изменения/удаления команды и неизменность prepared после отказа исправления логина.
Файловый тест проверяет реальные Docker ограничения и отсутствие host mounts/egress.
Симулированные AV peers используются только для проверки отказов/возраста;
успешные PDF/EICAR сценарии используют настоящий parser и ClamAV.

## Внешние ограничения

Обновление ClamAV с database.clamav.net в доступной среде завершилось timeout.
Дополнительная проверка URL через доступную сеть вернула HTTP 403.
Загруженная pinned база датирована 1 ноября 2026; по default 168 часам сканирование
отказывает. Для synthetic проверок явно установлено 720 часов. Это не успешная
приёмка свежести для production. Updater и хранилище баз настроены; реальная связь
и актуальная база проверяются оператором на целевом хосте.

KMS, реальные провайдеры/почта/TLS/копии/monitoring и целевой WSL не подключены и не
проверены. Nginx template проверен nginx -t с одноразовым synthetic сертификатом в
изолированном контейнере; он не установлен на реальный сервер. Прямого публичного
запуска, покупок, merge в main и передачи настоящих ПДн не было.
