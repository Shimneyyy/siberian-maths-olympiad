# История повторной реализации объявлений

8 ноября 2026 доступная work была восстановлена до 1c8422d (D05). Реализация D04
не обнаружилась в доступных файлах/reflog/объектах; прежняя среда была недоступна.
Это не доказывало удаления её диска. Пользователь подтвердил отсутствие архива/патча
и разрешил повторную разработку. Старые результаты новой реализации не приписывались.
[Первоначальный план](https://github.com/Shimneyyy/siberian-maths-olympiad/blob/a921c0981bc041336760c309e1dd527c61202140/docs/D04_REIMPLEMENTATION.md),
[итоговая запись](https://github.com/Shimneyyy/siberian-maths-olympiad/blob/a921c0981bc041336760c309e1dd527c61202140/docs/DECISIONS.md#L515).

Принятые важные решения: главный назначенного года, серверная адресация года/площадки,
отменившиеся в аудитории, неизменяемая публикация, исправление новым объявлением,
текст без исполнения HTML, важная публикация атомарна с outbox/аудитом.

Для cleanup неизменяемых публикаций использовались отдельные схемы/временные БД,
а не отключение SQL-триггера. После HMR-конфликтов выделен runtime browser-runner.
Эти выводы сохранены в [контракте](../../contracts/COMMUNICATIONS.md) и
[проверках](../../TESTING.md). План повторной разработки завершён исторически;
он не является заданием реализовать D04 заново.
