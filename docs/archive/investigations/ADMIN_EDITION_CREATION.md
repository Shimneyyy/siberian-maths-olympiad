# Создание выпуска через кабинет администратора

21 ноября 2026, work1, база 5a23275; итоговая ревизия — коммит с этим отчётом.
Запрос пользователя — добавить задачу в очередь и реализовать создание выпуска в UI.
Решение [ADR-014](../../decisions/ADR-014-admin-edition-creation.md),
контракт [участия](../../contracts/PARTICIPATION.md#выпуск-и-запись).

Добавлены createAdminEdition и POST /api/admin/editions, форма в пустом и заполненном
кабинете. Другие роли не получают provisioning. Пароль/лимит/подтверждение,
транзакционный повтор роли, стабильный UUID и атомарный аудит обязательны.
Новых миграций нет. Bootstrap администратора и production-инфраструктура не менялись.

## Проверки

- lint / typecheck — успешно.
- test:db — 140/140, в том числе две admin service-регрессии.
- test:account-switch — 4/4; новый UI-сценарий прошёл без CLI создания выпуска.
- build / check:build — успешно, 83 server traces, local secrets excluded.
- Документация: 47 Markdown-файлов, 318 относительных ссылок и 71 ссылка на npm scripts;
  несуществующих путей/команд и незакрытых code fences нет.

Build сохранил три прежних предупреждения dynamic filesystem tracing.
Checker traces проверяет пути, не является универсальным сканером секретов.

Service-регрессия проверяет роли/почту/пароль/схему/подтверждение, отсутствие побочных
назначений/сроков, повтор после изменения настроек, гонку двух UUID одного года,
один аудит и rollback при его отказе. Browser-сценарий создаёт выпуск из пустого UI,
теряет ответ после настоящего commit, повторяет тот же UUID, задаёт сроки UTC+7,
назначает главного и отвергает дубль без изменения прежних настроек.

Files/ops/load-наборы не повторялись: файловый runtime, участнические запросы и
backup-формат не менялись. Предыдущие успехи не объявляются проверкой этого коммита.
